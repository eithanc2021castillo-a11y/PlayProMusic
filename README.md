## ✨ Características

- 🎵 Reproducción de música
- ▶️ Interfaz moderna
- 🎨 Diseño oscuro y colorido
- 🎚️ Ecualizador
- ❤️ Sección de favoritos
- 📱 Optimizado para Android

## 📦 Instalación

1. Descarga **PlayProMusic.apk** desde el botón de arriba.
2. Abre el archivo APK en tu dispositivo Android.
3. Permite la instalación si Android lo solicita.
4. Instala y disfruta de **PlayProMusic**.
   

## 🔐 Seguridad

Las claves de API utilizadas por los servicios del proyecto no se almacenan dentro de la aplicación ni en este repositorio.
